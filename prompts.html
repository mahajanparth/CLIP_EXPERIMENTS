Words Change the Experiment

How much do phrasing and context change the same class? Compare descriptions of one image, then compare three classifier strategies using exactly the same images and labels. Ensembling averages normalized text embeddings before scoring.

Part 1One image, different words

Every line is encoded separately, so each wording is a different point in CLIP’s space. The image does not change; only the words do.

Part 2Three ways to build the same classifier

Each strategy turns the same class labels into one text vector per class. Every image is assigned to the class with the highest cosine. Images and labels stay fixed; only the words change.
