# Caltech-101 · 50 categories × 50 photographs

Dataset creators: Fei-Fei Li; Marco Andreeto; Marc'Aurelio Ranzato; Pietro Perona (Caltech-101 dataset creators). [Official source](https://data.caltech.edu/records/mzrjq-6wc02); [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Original JPEG bytes are preserved. Each manifest record identifies the original archive member and SHA-256. No repeated images or synthetic augmentation are used to reach the count. This educational subset is not a benchmark split.

Archive MD5: `3138e1922a9193bfa496528edbbc45d0`. Categories with fewer than 50 files are excluded, along with background, redundant face collections, cartoons, symbols, and scans.
